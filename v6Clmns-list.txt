====================================================================================================
SECTION 2: DETAILED DATA DICTIONARY & FORMULAS (ALPHABETICAL)
====================================================================================================

allow_concurrent_trades
  Data Type   : bool (True | False, default: False)
  Description : Execution control parameter toggle permitting (True) or suppressing (False) new trade
                entries while existing positions remain open.
  Logic       : If False, signals occurring while in_trade=True are suppressed. If True, multiple
                concurrent positions are tracked independently with dedicated trade_id and lifecycles.

concurrent_trades_count
  Data Type   : int
  Description : Bar-level telemetry recording the number of simultaneous active trades open on the current bar.
  Formula     : len(active_trades) on current candle. Used for portfolio margin exposure tracking.

confirmation_time
  Data Type   : timestamp with time zone (ISO 8601)
  Description : Timestamp of the setup confirmation candle (Bar +3 Open from initial signal trigger).
  Role        : Serves as the scheduled execution bar where the entry order is executed.

direction
  Data Type   : varchar ('LONG' | 'SHORT')
  Description : Trade execution direction side. Currently 'LONG' for floor trader support bounce setups.

ecpatt_1, ecpatt_2, ecpatt_3
  Data Type   : varchar (string)
  Description : 1st, 2nd, and 3rd detected technical analysis candlestick pattern names on confirmation bar.
  Examples    : 'Hammer', 'Bullish_Engulfing', 'Morning_Star'. Extracted via loss_profile.candles.

entry_1, entry_2, entry_3, entry_4
  Data Type   : varchar (string)
  Description : Exact backwards-compatibility aliases for epatt_1, epatt_2, epatt_3, epatt_4.
  Role        : Retained in database schema for loss-profile CLI compatibility (--dist entry_1).

entry_fees
  Data Type   : double (currency)
  Description : Transaction cost / broker commission incurred upon trade entry fill.

entry_price
  Data Type   : double (price)
  Description : Execution fill price executed at the confirmation candle Open (Bar +3 Open).

entry_time
  Data Type   : timestamp with time zone (ISO 8601)
  Description : Exact timestamp when broker fill occurs (separated from confirmation to support pending/limit orders).

epatt_1
  Data Type   : varchar (string)
  Description : 3 setup candles strictly before entry bar in Direction+Color format.
  Formula     : pos(-3) || '-' || pos(-2) || '-' || pos(-1), e.g. 'DR-DR-UG'.

epatt_2
  Data Type   : varchar (string)
  Description : 2 setup candles before entry + entry candle in Direction+Color format.
  Formula     : pos(-2) || '-' || pos(-1) || '-' || pos(0), e.g. 'DR-UG-UG'.

epatt_3
  Data Type   : varchar (string)
  Description : Straddle pattern centered on entry candle (1 before + entry + 1 after).
  Formula     : pos(-1) || '-' || pos(0) || '-' || pos(+1), e.g. 'UG-UG-UR'.

epatt_4
  Data Type   : varchar (string)
  Description : 4-candle forward follow-through pattern from entry.
  Formula     : pos(0) || '-' || pos(+1) || '-' || pos(+2) || '-' || pos(+3), e.g. 'UG-UR-DG-UG'.

epcpatt_1, epcpatt_2, epcpatt_3
  Data Type   : varchar (string)
  Description : 1st, 2nd, and 3rd detected TA candlestick pattern names on preceding setup bar (Bar 0).

exit_fees
  Data Type   : double (currency)
  Description : Transaction cost / broker commission incurred upon trade exit fill.

exit_price
  Data Type   : double (price)
  Description : Fill price at trade termination.
  Logic       : Equals tp_price on TP hit, safe_sl on SL hit, or close price on session cutoff.

exit_reason
  Data Type   : varchar ('TP' | 'SL' | 'CLOSED')
  Description : Categorical trade termination classification trigger.
  Values      : 'TP' (Take Profit hit), 'SL' (Stop Loss hit), 'CLOSED' (manual or session cutoff).

exit_time
  Data Type   : timestamp with time zone (ISO 8601)
  Description : Exact timestamp when position closes.

fib_bsl
  Data Type   : double (ratio: 0.0 to 0.786)
  Description : In-Trade Maximum Fibonacci extension ratio reached before Stop Loss was triggered.
  Grid        : 0.236, 0.382, 0.500, 0.618, 0.786. Automatically set to 0.786 on TP win trades.

fib_bsl_ambiguous
  Data Type   : bool (True | False)
  Description : Ambiguity flag set to True if highest in-trade Fibonacci touch occurred on the exact
                same candle where Stop Loss was triggered.

fingerprint
  Data Type   : varchar (64-char hex)
  Description : SHA-256 hash uniquely fingerprinting strategy parameters, timeframe, and execution window.

holding_bars
  Data Type   : bigint (integer count)
  Description : Total number of candles elapsed from entry_time to exit_time (replaces duration_candel).
  Formula     : exit_bar_index - entry_bar_index.

holding_seconds
  Data Type   : double (seconds)
  Description : Total wall-clock duration of active trade in seconds.
  Formula     : (exit_time - entry_time).total_seconds().

is_win
  Data Type   : boolean / integer (1 | -1 | 0)
  Description : Binary trade outcome flag. 1 (or True) for profitable TP hit, -1 (or False) for loss.

lot_size
  Data Type   : double (standard FX lots)
  Description : Executed forex position volume in standard lots.
  Formula     : size / 100,000 (e.g. 0.01 micro lot, 0.10 mini lot, 1.00 standard lot).

lower_pivot
  Data Type   : double (price)
  Description : Generalized lower channel / support boundary (Floor Trader S1).
  Formula     : (2 * pivot) - High_20. Serves as the primary setup bounce trigger condition (Close <= lower_pivot).

mae (Maximum Adverse Excursion)
  Data Type   : double (price points)
  Description : Maximum unrealized drawdown experienced while in position.
  Formula     : entry_price - min(Low_entry..exit). Identifies drawdown tolerance required for winning trades.

mfe (Maximum Favorable Excursion)
  Data Type   : double (price points)
  Description : Maximum unrealized profit peak experienced while in position.
  Formula     : max(High_entry..exit) - entry_price. Identifies near-miss winners for trailing/BE stop tuning.

pfib15_be_hit, pfib30_be_hit, pfib60_be_hit   [NEW IN V6]
  Data Type   : boolean (True | False)
  Description : Multi-horizon post-exit Breakeven breach telemetry.
  Logic       : Evaluated across 15, 30, and 60 forward candles strictly following trade exit.
                Set to True if price retreated and touched trade entry_price (Breakeven level) within horizon.
                Enables precise runner retention analysis (determining if runners get stopped at BE).

pfib15_bsl, pfib30_bsl, pfib60_bsl             [NEW IN V6]
  Data Type   : double (Fibonacci extension ratio: 0.236 to 3.000)
  Description : Multi-horizon post-exit Fibonacci runner excursion reached before hitting SL or BE.
  Grid        : 14-ratio grid: 0.236, 0.382, 0.500, 0.618, 0.786, 1.000, 1.272, 1.414, 1.618, 1.786, 2.000, 2.272, 2.618, 3.000.
  Logic       : Evaluated across 15, 30, and 60 forward candles after trade exit.
                Measures maximum post-exit continuation excursion before any invalidation occurs.
                Essential for evaluating trailing runners and multi-stage Take Profit extensions (R2, R3).

pfib15_sl_hit, pfib30_sl_hit, pfib60_sl_hit   [NEW IN V6]
  Data Type   : boolean (True | False)
  Description : Multi-horizon post-exit Stop Loss breach telemetry.
  Logic       : Set to True if price retreated and breached the trade's safe_sl level within 15, 30, or 60 candles.

pivot
  Data Type   : double (price)
  Description : 20-period rolling Floor Trader Pivot level shifted by 1 bar.
  Formula     : (High_20 + Low_20 + Close_-1) / 3.

pivot_sl
  Data Type   : double (price)
  Description : Structural stop loss price level anchored directly to lower_pivot support (S1).

pivot_sl_hit
  Data Type   : boolean (True | False)
  Description : Cumulative breach flag set to True if Low touched or breached pivot_sl at any point while in trade.
  Formula     : Low <= pivot_sl.

pnl
  Data Type   : double (currency)
  Description : Total net realized monetary profit/loss in currency units ($).
  Formula     : realized_pnl * size - (entry_fees + exit_fees).

primary_sl
  Data Type   : double (price)
  Description : Aggressive stop loss price level anchored directly to Close of setup signal candle (Bar 0 Close).

primary_sl_hit
  Data Type   : boolean (True | False)
  Description : Cumulative breach flag set to True if Low touched or breached primary_sl at any point while in trade.
  Formula     : Low <= primary_sl.

projected_rr
  Data Type   : double (ratio)
  Description : Standardized projected Risk:Reward ratio using safe_sl (alias for projected_rr_safe).

projected_rr_primary
  Data Type   : double (ratio)
  Description : Projected Risk:Reward ratio using aggressive primary SL.
  Formula     : (tp_price - entry_price) / risk_primary.

projected_rr_safe
  Data Type   : double (ratio)
  Description : Projected Risk:Reward ratio using dynamic safe SL.
  Formula     : (tp_price - entry_price) / risk_safe.

r1
  Data Type   : double (price)
  Description : Backwards-compatibility alias for upper_pivot.

realized_pnl
  Data Type   : double (price points)
  Description : Absolute trade price point gain or loss.
  Formula     : exit_price - entry_price.

realized_pnl_pct
  Data Type   : double (percentage)
  Description : Trade return as a percentage.
  Formula     : (realized_pnl / entry_price) * 100.

return_pct
  Data Type   : double (decimal fraction)
  Description : Trade return as a decimal fraction (e.g. +0.0050 = +0.50%). Used for compounding.
  Formula     : realized_pnl / entry_price.

risk_amount
  Data Type   : double (currency)
  Description : Total monetary capital risked on trade.
  Formula     : risk_safe * size (equals fixed risk_per_trade parameter, e.g. $100.00).

risk_pivot
  Data Type   : double (price points)
  Description : Absolute price risk distance from entry to structural pivot_sl.
  Formula     : max(entry_price - pivot_sl, 1e-6).

risk_primary
  Data Type   : double (price points)
  Description : Absolute price risk distance from entry to aggressive primary_sl.
  Formula     : max(entry_price - primary_sl, 1e-6).

risk_safe
  Data Type   : double (price points)
  Description : Absolute price risk distance from entry to conservative safe_sl.
  Formula     : max(entry_price - safe_sl, 1e-6).

r_multiple
  Data Type   : double (multiplier)
  Description : Realized trade return normalized by active risk capital.
  Formula     : pnl / risk_amount (e.g. +1.85R on win, -1.00R on full loss).

s1
  Data Type   : double (price)
  Description : Backwards-compatibility alias for lower_pivot.

safe_sl
  Data Type   : double (price)
  Description : Conservative dynamic stop loss level incorporating swing low and channel range buffer.
  Formula     : swing_low - 0.5 * (upper_pivot - lower_pivot).

safe_sl_hit
  Data Type   : boolean (True | False)
  Description : Cumulative breach flag set to True if Low touched or breached safe_sl while in trade.
  Formula     : Low <= safe_sl.

session
  Data Type   : varchar ('Asian' | 'London' | 'New York' | 'London/NY Overlap')
  Description : Forex trading session active at confirmation/entry timestamp (UTC hours).
  Mapping     : Asian (21:00-07:00), London (07:00-12:00), Overlap (12:00-16:00), New York (16:00-21:00).

signal_time
  Data Type   : timestamp with time zone (ISO 8601)
  Description : Timestamp of initial trigger bar where condition Close <= lower_pivot first occurs (Bar 0).

size
  Data Type   : double (units / contracts)
  Description : Dynamic position size in units scaled to equalize monetary risk per trade.
  Formula     : risk_per_trade / risk_safe.

sl_price
  Data Type   : double (price)
  Description : Active Stop Loss execution price (equals safe_sl).

status
  Data Type   : varchar ('CLOSED' | 'OPEN')
  Description : Trade lifecycle state. 'CLOSED' for finalized trades, 'OPEN' for active positions.

strategy_name
  Data Type   : varchar
  Description : Registered strategy identifier string ('classic_floor_mod_v6').

swing_low
  Data Type   : double (price)
  Description : Lowest body low across Bars 0 through 3 (from signal trigger through confirmation bar).
  Formula     : min(body_low[signal_bar .. entry_bar]) where body_low = min(Open, Close).

symbol
  Data Type   : varchar (e.g. 'EURUSD')
  Description : Currency pair or market ticker.

timeframe
  Data Type   : varchar (e.g. '5m')
  Description : Candle resolution timeframe.

tp_price
  Data Type   : double (price)
  Description : Take Profit target price level frozen at upper_pivot (R1) captured from signal bar.

trade_id
  Data Type   : bigint (sequential integer)
  Description : Chronological sequential trade identifier assigned per executed trade (1, 2, 3...).

uid
  Data Type   : bigint (primary key)
  Description : Unique integer primary key index across database tables (1..N).

upper_pivot
  Data Type   : double (price)
  Description : Generalized upper channel / resistance boundary (Floor Trader R1).
  Formula     : (2 * pivot) - Low_20. Serves as the fixed Take Profit target.

vbt_trade_id
  Data Type   : bigint
  Description : VectorBT backtest simulator trade identifier.


====================================================================================================
SECTION 3: STRATEGY-LEVEL POST-TRADE RUNNER EXCURSION ARCHITECTURE (V6 INNOVATION)
====================================================================================================

Why Include pfib at the Strategy Level?
---------------------------------------
In older versions (v2..v5), post-trade Fibonacci runner excursions were calculated in a decoupled,
secondary post-processing CLI ('post-trade-analysis'). This caused three friction points:
  1. Required a second database connection, extra views ({strat}_trades_pfib), and out-of-band sync.
  2. Loss profiler ('loss-profile') could not filter or slice by runner potential on fresh backtests.
  3. Runners could not be evaluated directly inside the backtest engine for partial TP scaling.

In classic_floor_mod_v6, the strategy engine directly forward-evaluates the 15, 30, and 60 candle
post-exit horizons upon trade closure, baking the 9 essential runner excursion metrics directly into
the trade output table:

  1. 15-Candle Horizon (Short-term Runner Continuation):
     - pfib15_bsl    : Highest Fibonacci extension (0.236..3.000) reached before SL or BE.
     - pfib15_be_hit : True if price retreated back to entry price within 15 bars post-exit.
     - pfib15_sl_hit : True if price collapsed to safe_sl within 15 bars post-exit.

  2. 30-Candle Horizon (Medium-term Trend Extension):
     - pfib30_bsl    : Highest Fibonacci extension reached before SL or BE.
     - pfib30_be_hit : True if price retreated back to entry price within 30 bars post-exit.
     - pfib30_sl_hit : True if price collapsed to safe_sl within 30 bars post-exit.

  3. 60-Candle Horizon (Macro Runner / Session Continuation):
     - pfib60_bsl    : Highest Fibonacci extension reached before SL or BE.
     - pfib60_be_hit : True if price retreated back to entry price within 60 bars post-exit.
     - pfib60_sl_hit : True if price collapsed to safe_sl within 60 bars post-exit.

Analytical Value of Strategy-Level pfib:
  - Immediate Runner Viability: Instantly measure what percentage of TP trades continue to 1.272, 1.618, or 2.000.
  - Breakeven Retention: If pfib15_be_hit is high, moving stop to Breakeven at TP chokes runners prematurely.
  - Multi-Stage Exit Optimization: Informs dynamic scaling (e.g. exit 70% at upper_pivot, trail 30% to 1.618).
