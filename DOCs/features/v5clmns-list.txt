pivot=20-period rolling Floor Trader Pivot level ((High20 + Low20 + PrevClose) / 3)
s1=First floor support level ((2 * pivot) - High20)
r1=First floor resistance level and frozen Take Profit target ((2 * pivot) - Low20)
entries=Boolean flag indicating trade entry on confirmation candle Open (Bar +3)
exits=Boolean flag indicating trade exit when Take Profit or Stop Loss is reached
in_trade=Boolean flag indicating active in-position candle
trade_id=Sequential integer identifier for each trade
entry_price=Fill price executed at confirmation candle Open (Bar +3 Open)
sl_price=Dynamic Stop Loss price set at swing_low minus half (r1 - s1) range buffer
tp_price=Take Profit target price frozen at setup r1 level
exit_price=Fill price at trade exit (tp_price on win, sl_price on loss)
exit_reason=Categorical trade exit trigger ('TP' for win, 'SL' for loss)
realized_pnl=Absolute price point gain or loss (exit_price - entry_price)
realized_pnl_pct=Percentage return on trade ((realized_pnl / entry_price) * 100)
is_win=Binary outcome indicator (1 for TP win, -1 for SL loss, 0 otherwise)
signal_time=Timestamp of initial setup trigger candle where close <= s1 (Bar 0)
confirmation_time=Timestamp of scheduled entry confirmation candle (Bar +3)
swing_low=Lowest body low (min(open, close)) across signal through confirmation bars (Bars 0..3)
fib_bsl=Maximum Fibonacci ratio (0.236, 0.382, 0.5, 0.618, 0.786) reached before Stop Loss hit (0.786 on TP)
fib_bsl_ambiguous=Boolean flag indicating if highest Fibonacci touch occurred on the exact same bar as Stop Loss hit
epatt_1=3 setup candles strictly before entry bar in Direction+Color format (pos-3, pos-2, pos-1)
epatt_2=2 setup candles before entry plus entry candle in Direction+Color format (pos-2, pos-1, pos)
epatt_3=Straddle pattern around entry candle in Direction+Color format (pos-1, pos, pos+1)
epatt_4=4-candle forward follow-through pattern in Direction+Color format (pos, pos+1, pos+2, pos+3)
ecpatt_1=1st confirmation candlestick pattern classification name
ecpatt_2=2nd confirmation candlestick pattern classification name
ecpatt_3=3rd confirmation candlestick pattern classification name
epcpatt_1=1st preceding candlestick pattern classification name
epcpatt_2=2nd preceding candlestick pattern classification name
epcpatt_3=3rd preceding candlestick pattern classification name

NEXT STRATEGY VERSION ARCHITECTURE PROPOSAL:
- Generalized Nomenclature:
  upper_pivot=Generalized upper channel/target level across calculation engines (replaces hardcoded Floor Trader 'r1')
  lower_pivot=Generalized lower boundary/support level across calculation engines (replaces hardcoded Floor Trader 's1')
  Standardize 'epatt_1..4' as Canonical (deprecates redundant 'entry_1..4' aliases)

- 4-Phase Lifecycle Timestamps:
  signal_time=Timestamp of initial setup trigger candle where condition is first detected (Bar 0)
  confirmation_time=Timestamp of setup confirmation candle (3rd candle from signal bar)
  entry_time=Exact timestamp when order is filled and position is entered (can differ from confirmation if delayed/pending)
  exit_time=Exact timestamp when trade is closed (TP hit, SL hit, or session close)

- Duration & Holding Metrics:
  holding_bars=Total candle count elapsed between entry_time and exit_time (standardizes holding_bars / duration_candel)
  holding_seconds=Total wall-clock elapsed time of active trade in seconds (exit_time - entry_time)

- Multi-tier Stop Loss Hierarchy:
  primary_sl=Aggressive stop loss price level anchored to the Close of the setup signal candle (Bar 0 Close)
  pivot_sl=Structural stop loss price level anchored to lower_pivot support level (s1)
  safe_sl=Conservative dynamic stop loss set at swing_low minus half (upper_pivot - lower_pivot) range buffer (replaces legacy sl_price)

- Multi-tier Trade-Level SL Breach Telemetry:
  primary_sl_hit=Boolean flag set to True if price touched or breached primary_sl (low <= primary_sl) at any point during trade lifecycle
  pivot_sl_hit=Boolean flag set to True if price touched or breached pivot_sl (low <= pivot_sl) at any point during trade lifecycle
  safe_sl_hit=Boolean flag set to True if price touched or breached safe_sl (low <= safe_sl) at any point during trade lifecycle

- Risk Distances, Sizing & Fees:
  risk_primary=Absolute price risk distance to primary_sl (entry_price - primary_sl)
  risk_pivot=Absolute price risk distance to pivot_sl (entry_price - pivot_sl)
  risk_safe=Absolute price risk distance to safe_sl (entry_price - safe_sl)
  size=Executed position volume in units or contracts
  lot_size=Standardized forex trading lot volume (e.g. 0.01 micro, 0.10 mini, 1.00 standard lot = size / 100,000 for standard FX contracts)
  risk_amount=Total monetary capital risked on trade in currency units (risk_distance * size)
  entry_fees=Broker/exchange commission and spread costs incurred on entry fill
  exit_fees=Broker/exchange commission and spread costs incurred on exit fill

- Risk:Reward & Realized Expectancy:
  projected_rr_primary=Projected R:R ratio using primary_sl ((tp_price - entry_price) / risk_primary)
  projected_rr_safe=Projected R:R ratio using safe_sl ((tp_price - entry_price) / risk_safe)
  r_multiple=Realized return normalized by active risk distance (realized_pnl / active_risk_distance)
  pnl=Total net realized monetary profit/loss (harmonizes realized_pnl)
  return_pct=Total net percentage return on trade (harmonizes realized_pnl_pct)

- In-Trade Excursion Extremes (MFE / MAE):
  mfe=Maximum Favorable Excursion (highest price reached during trade lifecycle minus entry_price)
  mae=Maximum Adverse Excursion (entry_price minus lowest price reached during trade lifecycle)

- Direction, Status & Market Regime:
  direction=Trade direction string ('LONG' or 'SHORT')
  status=Position lifecycle state ('CLOSED' or 'OPEN')
  session=Market trading session at trade entry (Asian, London, New York, London/NY Overlap)

- Execution Controls & Multi-Position Telemetry:
  allow_concurrent_trades=(bool: True | False, default: False) Parameter controlling whether new setup signals are taken while an existing trade is open. If False, new signals are suppressed until all open trades exit. If True, concurrent/overlapping positions are permitted with independent trade_id tracking.
  concurrent_trades_count=Integer telemetry column tracking the number of simultaneous active trades open on the current bar (monitors cumulative margin exposure).

- SL Optimization & Robustness Analytics (Why We Compute These Flags):
  1. Identifies premature stop-outs: where tighter SL was hit (primary_sl_hit=True) but wider SL survived to hit TP (safe_sl_hit=False, is_win=1).
  2. Identifies high-efficiency trades: where price never threatened tighter stops (primary_sl_hit=False, is_win=1), proving that a tighter primary_sl could have safely yielded a significantly higher R-multiple.
  3. Identifies runaway losses: where all stops were breached, indicating patterns where tighter stop execution would have preserved capital.
  4. MFE/MAE Diagnostics: reveals near-miss winners (high MFE before hitting SL) as prime candidates for Break-Even (BE) and trailing stop rules.
