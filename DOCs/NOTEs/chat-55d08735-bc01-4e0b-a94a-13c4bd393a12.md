  - `uv run loss-profile --dist entry_1`: 3-candle setup pattern distribution (`entry_1`..`entry_4`).
  - `uv run loss-profile --dist prr`: Projected R:R bracket distribution (`< 2.0`, `2.0-3.0`, `3.0-4.0`, `4.0-5.0`, `>= 5.0`).
  - `uv run loss-profile --dist duration`: Candle duration bracket distribution.
  - `uv run loss-profile --dist loss`: Dollar loss amount severity breakdown.
  - `uv run loss-profile --dist monthly`: Monthly time buckets.
  - `uv run loss-profile --dist weekly`: Weekly time buckets.
- **Composable Modifiers Implemented**:
  - `--filter "entry_1 = DR-DR-DR"`: Filter trades by pattern expression.
  - `--losses-only` / `--wins-only`: Restrict breakdowns to losing or winning trades.
  - `--min-trades N`: Filter out thin rows with fewer than N trades.
  - `--sort win%|trades|pnl`: Custom sorting.
  - `--top N` / `--bottom N`: Slice top or bottom N distribution rows.
  - `--compare <axis>`: Cross-axis side-by-side pivot breakdown (e.g., `--dist prr --compare entry_1`).
  - `--head N`: Trades head table viewer.
  - `--output markdown`: Output as markdown tables.
